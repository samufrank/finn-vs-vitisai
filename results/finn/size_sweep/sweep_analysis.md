# FINN size sweep — analysis

Generated by `analysis/extract_sweeps.py`. Source data: `resource_summary.csv` + per-build `final_hw_config.json` + `build.log`. To regenerate, run `python3 analysis/extract_sweeps.py` from the repo root.

Companion experiment to the `target_fps` sweep. Same four (model, precision) combinations; this sweep varies **model size** at fixed `target_fps=1000`. Goals: (1) characterize how FINN resource utilization scales with topology size; (2) test the design-space-headroom claim — that INT4 admits larger models than INT8 on the same ZU3EG.
